# Whiteboard Canvas Card

A modern, responsive, infinite-canvas whiteboard drawing and 300 DPI printing card for Home Assistant Lovelace.

## Features

- 🎨 **Infinite Canvas**: Draw without boundaries with smooth pinch-to-zoom and pan support.
- 🔄 **Multi-Terminal Real-Time Sync & Per-Device Undo/Redo**: Synchronize strokes, text, and undo/redo actions across all devices in real time; each device can only undo its own strokes without disturbing others' drawings.
- ✍️ **Fluid Bézier Strokes**: Anti-aliased stroke rendering with palm and touch jitter suppression.
- 📝 **Inline Draggable Text Box**: Direct on-canvas typographic typing with multi-line input, 4 font sizes, and custom colors.
- 🖨️ **300 DPI High-Resolution Output**: Content bounding box auto-detection scaled to physical paper sizes (A4, A3, Letter, Thermal Roll).
- 🚀 **One-Click Workflows**: `Save + New`, `Discard + New`, and `Print + New`.
- 🕒 **Integrated History Gallery**: Re-edit prior sketches, reprint, or download anytime with IndexedDB persistent storage.
- 🌐 **Multi-Mode Printing**: Supports direct IPP, Home Assistant service bridge, external print gateway, or system OS print dialog.
